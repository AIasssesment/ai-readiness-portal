# Architecture Decision Records (ADR)

Тут зберігаємо короткі записи про прийняті архітектурні/продуктові рішення в порталі.
Кожен файл — це один ADR у форматі `NNNN-короткий-заголовок.md`.

## Навіщо

- Фіксуємо, *що* ми зробили і *чому*, щоб через місяць не відновлювати контекст з нуля.
- Робимо зміни простежуваними: рішення, альтернативи, наслідки.

## Статуси

`Draft` → `In Discussion` → `Decided` → `Implemented` → `Abandoned` / `Superseded`
